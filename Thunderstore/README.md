# ShapingReshaped

Tweaks shaping shrines to have a downside

* Changes initial curse from shrine to 20% (can be configured)
* Adds 30% curse penalty from reviving with the shrine (can be configured)
* Reduces shaping shrine spawn weight by 50% (can be configured)
